# Water Quality Monitoring System 💧📱

This project is a comprehensive solution for monitoring water quality using **Android Development** and **Machine Learning**. It classifies water quality based on various parameters (like pH, Turbidity, etc.) using a custom-trained **TensorFlow Lite** model.

## 🌟 Key Features
* **Real-time Monitoring:** Interface to track water quality metrics.
* **ML Integration:** Uses a `water_quality_model.tflite` for on-device inference.
* **Trained Model:** Developed using Python (Jupyter Notebook) with high accuracy.
* **Android Studio Project:** Built with Kotlin using Gradle.

## 🛠️ Tech Stack
* **Mobile:** Android Studio, Kotlin, Gradle.
* **Machine Learning:** TensorFlow Lite, Scikit-learn, Pandas.
* **Training Environment:** Jupyter Notebook (Python).

## 📂 Project Structure
- `src/`: Source code for the Android application.
- `Model_training/`: Python scripts and the exported TFLite model.
